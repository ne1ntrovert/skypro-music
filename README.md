# Skypro.Music

## Запуск

```bash
npm install
npm run dev
```

Открыть http://localhost:3000

## Что уже сделано

- Вёрстка перенесена на Next.js (App Router, TypeScript). Главная разбита на компоненты в `src/components`, у каждого своя папка и свой css-модуль, общие стили в `globals.css`
- Страницы входа и регистрации (`/signin`, `/signup`)
- Шрифт Montserrat подключён через Google Fonts в layout
- Меню в шапке открывается и закрывается по бургеру
- Треки берутся из моковых данных (`src/data.ts`)
- Фильтры по исполнителю, году выпуска и жанру. Списки исполнителей и жанров собираются из треков, открыт может быть только один фильтр.
- Плеер на Redux Toolkit. Клик по треку запускает его, у текущего трека в списке показывается точка, во время воспроизведения она пульсирует. Play/pause работают, иконка меняется, громкость регулируется ползунком

## Структура

```
src/
  app/          страницы и layout
  components/   компоненты главной страницы
  store/        redux store и слайс плеера
  data.ts       моковые треки
  types.ts      тип трека
public/img/     картинки и спрайт иконок
```
