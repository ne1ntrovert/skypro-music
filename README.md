# Skypro.Music

## Запуск

```bash
npm install
npm run dev
```

Открыть http://localhost:3000

## Структура

```
src/
  api/          запросы к API и типы ответов
  app/          страницы и layout
    (main)/     общий layout для главной, подборок и избранного
    signin/     вход
    signup/     регистрация
  components/   компоненты главной страницы
  store/        redux store, слайсы плеера, авторизации и избранного
  utils/        форматирование времени, работа с localStorage
  types.ts      типы трека, подборки, пользователя
public/img/     картинки и спрайт иконок
```

Треки и подборки берутся с https://webdev-music-003b5b991590.herokuapp.com, данные для фильтров собираются из полученных треков. При входе пользователь и токены сохраняются в localStorage, при выходе очищаются.

Лайки доступны только после входа, состояние лайка синхронизируется с сервером и показывается и в списке, и в плеере. Избранные треки лежат на странице `/favorites`, без входа она редиректит на `/signin`. Для авторизованных запросов есть обёртка `withReAuth`: при 401 она обновляет access-токен через refresh и повторяет запрос, если refresh тоже не принят, сессия сбрасывается.
